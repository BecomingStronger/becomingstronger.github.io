# becomingstronger.github.io
## Editing the site

`python3 tools/edit.py` starts a local click-to-edit server at
http://127.0.0.1:5026/ (or open "Site Editor" from /Applications). Pick a
page, click any text, type, Save (⌘S), then Publish; publish commits and
pushes, and GitHub Pages redeploys in about a minute. Saves splice the exact
bytes of the edited text back into the source file, so the hand-written HTML
never gets reflowed. Dynamic content (charts, the blog list) is hidden in
edit mode; edit those in the page source.
